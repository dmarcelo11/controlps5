Guía de Despliegue

¿Cómo subir este catálogo a Netlify gratis?

Puedes tener tu catálogo publicado con tu propia dirección en un par de minutos.

1
Método más fácil

Netlify Drop (Arrastrar y Soltar)

  1. Guarda este código con el nombre index.html.
  2. Abre app.netlify.com/drop en tu navegador.
  3. Arrastra el archivo index.html (o la carpeta donde está guardado) dentro del área indicada.
  4. ¡Tu catálogo estará publicado inmediatamente en la nube de Netlify!
Sin registro obligatorio al inicio
2
Sincronizado

Conexión con GitHub

  1. Crea un repositorio en GitHub y sube este archivo index.html.
  2. Inicia sesión en Netlify.
  3. Haz clic en "Add new site" > "Import an existing project".
  4. Selecciona GitHub, escoge el repositorio y haz clic en "Deploy".
